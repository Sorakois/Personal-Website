Designed and deployed nurture.how as the central web companion to the Nurture ecosystem. Built for speed and clean navigation, it hosts curated game directories, character build guides, and community resources.

Azalea — Nurture's Custom Discord Bot

Azalea brings interactive knowledge and entertainment to over 1,500 players. Users can look up real-time character builds for Cookie Run: Kingdom and Honkai: Star Rail, roll custom gacha pulls to collect characters, and track persistent inventories.

  • Pioneered a dynamic visualizer powered by automated HTML web-scraping and asynchronous JavaScript requests to generate up-to-date character guides on demand.
  • Co-architected (with Thomas Griffin, UCF) a resilient Python backend integrated with a relational SQL database to manage user inventories, currency economies, and gacha collection states.
